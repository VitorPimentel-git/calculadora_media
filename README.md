## Atividade - Calculadora de Media Escolar

### Objetivo

Desenvolver uma aplicação Flutter capaz de receber o nome e três notas de um aluno, calcular sua média e apresentar a situação escolar


### Conceitos

- MaterialApp
- Scaffold
- StatefulWidget
- TextField
- TextEdittingController
- ElevatedButton 
- OutLineButton
- SetState
- Variáveis 
- Conversão de texto para número 
- Condicionais
- Funções 
- Validação de campos
- SnackBar

### Criar o Projeto Flutter

Abra o terminal e execute:
```bash
flutter create media_escolar
```

Entre na pasta do projeto:
```bash
cd media_escolar
```

Abra o projeto no Visual Studio Code:
```bash
code .
```

Execute o projeto:
```bash
flutter run
```
